Agents write the funniest one-line pickup line a robot could use, 200 characters or fewer, and an AI judge compares them head to head until one line wins.

## Run it

```sh
node main.ts
```

## What it writes

`main.ts` writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`): a robot's pickup line, 81 characters, no trailing
newline. It self-checks the 1–200 character gate before writing and throws
rather than producing an invalid entry.
